# 全季TN关键源区识别

用户授权在point21基础上跑通负荷—面积曲线识别流程，并要求QGIS/ArcGIS Pro操作说明。本版仅识别空间源区。

输入：v0.3.1 RM、RCC完整稻季kg/ha及kg/像元栅格。按处理独立归一化，保留有效零值。

流程：降序排序→面积/质量累积→端点固定且单调凹的三次B样条最小二乘拟合→导数=2及1求根→对应排名负荷阈值→保留同值像元的空间分级→实际面积/质量贡献与拟合预测对照。

三次样条为本版具体函数选择，文献依据为Zhuang et al. (2016)的拟合曲线求导与斜率分级框架。用16、24、32个内部结点对空间阈值进行敏感性核验，24为主结果，不把曲线拟合优度视为独立模型验证。

结果在独立功能分支保存；主线集成需用户批准。脚本、图表、说明和记录在.codex-work；最终分类GeoTIFF在正式成果目录。
