# 2024年三期累计TN流失栅格

版本：v0.3.1。情景：water_2024_point21。RM采用8月1—10日80/90/100 mm、8月21日末次补灌、22日起停灌，同时采用点位主动退水与管理表蓄水上限。施肥比例58:18:24，RCC管理沿用v0.3.0。

## 分期

|文件编号|管理时段|日期|天数|
|---|---|---|---:|
|00_season|完整稻季|6/1—9/23|115|
|01_basal|基肥后管理期|6/1—6/17|17|
|02_tillering|分蘖肥后管理期|6/18—7/5|18|
|03_topdress_to_maturity|追肥后至成熟期|7/6—9/23|80|

各分期统计当期每日出口TN流失之和。包含当前模型背景浓度等来源，不能解释为单次施肥的独立贡献。阶段长度不同，累计量用于分解全季负荷，若比较平均流失速率需另除以天数。

本分组采用用户确认的施肥管理日期，不是逐像元实测物候。成熟阶段计入末段，可完整覆盖全季；抽穗开花后的成熟阶段与孕穗在物候上区分，因而末段命名“追肥后至成熟期”。参考：[FAO水稻阶段说明](https://www.fao.org/4/t7202e/t7202e07.htm)。

## 文件与使用

最终本地目录：模型/2026.9.3/面上推广/2024/point21_三期累计TN流失。

- TN_RM或TN_RCC：对应实际土地分类像元，其他像元为NoData=-9999。
- kg_ha：单位面积累计流失量，kg/ha，适合阶段空间分布制图。
- kg_pixel：每像元累计流失质量，kg/像元，求和后除1000得到t。
- TN_Drain：RM田面排水或RCC系统出口折算水深，mm。
- 18张GeoTIFF：每处理全季及三期的两种负荷单位共16张，另有全季排水量2张。
- 各图沿用Rice_2021投影、网格及处理掩膜。有效零值保留为0。分期图建议使用一致的色阶边界，以便比较累计量大小。

RM田面出口与RCC田沟系统出口为各自流失边界。输入为2024气象、2021土地分类及2018施氮代理；本成果属于模型空间情景估算。

## 复现与核验

在仓库根目录用QGIS Python运行：

```powershell
python -B .codex-work/exports/export_stage_loads.py --root "项目数据根目录" --output "新的输出目录" --reference "run_20261029_140118_water_2024_point21_853fbd完整路径"
```

原始气象、管理与土壤等数据由本地root提供。脚本完整重跑115天，通过只读观察接口累加分期负荷。输出目录需为空，以保存已有成果。
