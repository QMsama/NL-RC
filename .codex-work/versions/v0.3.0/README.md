# 2024年RM水位规则迁移试算

## 规则与比较口径

在58:18:24施肥版本上比较RM水位规则。计算期2024-06-01至09-23，115天，RM 125036像元、RCC 74353像元。负荷为对应处理面积加权平均kg/ha，灌排量为对应处理像元平均mm。2024气象配合2021稻田分布及2018施氮代理输入，属于空间情景估算。

|情景|RM规则|
|---|---|
|基肥比例基线|原2024区域灌排规则|
|schedule21|8/1—10下限80、目标90、有效上限100 mm；8/21按当日目标末次补灌、22日起下限0；其余采用区域排水算法|
|point21|上述八月安排，同时全季采用点位普通阶段主动退水及原管理表蓄水上限|
|point24|同point21，末次补灌改为8/24，25日起下限0|

各情景保留2024管理日历。晒田阶段继续使用对应晒田规则。末次补灌仅在水位低于当日目标时发生。point情景改变主动退水和蓄水上限两个方面，不能把其差异仅归因于停灌日期。

## 全季结果

|情景|RM负荷 kg/ha|较基线变化|RM排水 mm|RM灌溉 mm|
|---|---:|---:|---:|---:|
|基肥比例基线|3.825585|0|333.450|411.031|
|schedule21|3.826525|+0.0246%|333.694|368.059|
|point21|4.885706|+27.7113%|387.856|422.143|
|point24|4.885706|+27.7113%|387.856|443.885|

RCC四情景均为5.457666 kg/ha。schedule21节省灌溉42.973 mm，全季负荷近似不变。point21与point24负荷近似相同，前者少灌21.743 mm。

point21相对基线的负荷增量主要来自6月（2.817693→3.628282 kg/ha）及7月（1.007886→1.158628 kg/ha）；8月为0.0000065→0.0987953 kg/ha。当前TN经验浓度公式不随本轮水位规则改变，逐日TN完全相同，负荷差异来自排水时序及体积。

## 点位规则来源及评价

当前点位优化采用8/21末次补灌。2022-06-05至09-23的RM原始水位36日期同日配对、保留零值，相关R²为Pearson相关系数平方，RMSE单位mm：

|点位候选|相关R²|RMSE mm|
|---|---:|---:|
|高水位＋8/21末次补灌|0.525298|26.469952|
|高水位＋8/24末次补灌|0.528895|26.829175|

8/21方案RMSE更低、季末回落匹配更好；8/24方案相关R²略高。评价包含用于管理校准的观测，属于校准一致性比较。当前2024面上试算未配对原始观测，水位及TN的2024验证R²、RMSE尚未计算。

## 复现与核验

使用QGIS 3.44.12的Python环境，在仓库运行regional_model.py，依次以--preset选择basal_2024_58_18_24、water_2024_schedule21、water_2024_point21、water_2024_point24；配置由configs读取，原始输入按运行清单在本地提供。脚本参数以--help为准。

7项单元测试通过；基线6张栅格与v0.2.0逐像元一致；RCC及RM逐日TN在各情景一致；schedule21八月前水位、排水和负荷一致；停灌后所有像元灌水为0；水量闭合最大误差9.1e-13；逐日累计负荷与汇总差小于1e-6 kg。有效上限、晒田标志及配置参考基线已核对。代码复核通过。

成果保存在feat/2024-water-management-transfer分支，供版本审查与用户验收。
